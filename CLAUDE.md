# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Personal portfolio for a Japanese university student (2nd year, software engineering) who is job hunting. The audience is recruiters. Japanese first (`<html lang="ja">`, copy is in Japanese), English later. Light mode only. Hosting target: Vercel (not set up yet).

## Commands

- `npm run dev` — dev server (Turbopack)
- `npm run build` / `npm start` — production build / serve
- `npm run lint` — ESLint (flat config: next core-web-vitals + typescript + prettier)
- `npm run format` / `npm run format:check` — Prettier (with `prettier-plugin-tailwindcss`, which sorts class names)

There is no test suite.

## Stack notes

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, npm.

- `next.config.ts` enables `cacheComponents` and `partialPrefetching`, and wires Tailwind through `@tailwindcss/turbopack`. MDX is not used — all content is TypeScript data.
- Tailwind v4 is configured in CSS, not a config file: design tokens (`accent`, `ink`, `tint`, `font-display`, menu animations) live in the `@theme` blocks of `src/app/globals.css`. Fonts (Inter, Noto Sans JP, Anton) are loaded in `src/app/layout.tsx` as CSS variables.
- Use the `@/` import alias for `src/`.

## Architecture

Content is typed data in `src/data/`, not a CMS or MDX:

- `src/data/projects.ts` exports `PROJECTS: Project[]` — the single source of truth for projects. The shape is `src/types/Project.ts`; `category` values come from `src/const/ProjectCategories.ts`. Much of the overview/features/gallery text is **placeholder dummy content** (see the banner at the top of the file) generated by the `dummy*` helpers; real screenshots belong in `public/projects/<slug>/`.
- `src/data/techStack.ts` maps tech tag names (matching `Project.tags`) to a brand color and icon. A tag with no entry here has no icon/color, so add one when introducing a new tag.
- `src/data/certifications.ts` holds certifications; news types/categories live in `src/types/News.ts` and `src/const/NewsCategories.ts`.

Routes (`src/app/`):

- `/` (`page.tsx`) composes home sections from `src/components/home/*` (hero, news, projects preview) plus `AboutMe` and `Contact`.
- `/projects` lists and filters projects (`components/projects/ProjectList`, `ProjectTabs`).
- `/projects/[slug]` is statically generated from `PROJECTS` via `generateStaticParams`, with `generateMetadata` per project and `notFound()` for unknown slugs. It renders the section components in `components/projects/detail/`, each of which takes a slice of the `Project` object.

Adding a project = add an entry to `PROJECTS` (plus images under `public/projects/`); the list, home preview, and detail page all derive from it.

`src/components/util/` holds shared UI. `PrimaryButton` renders a `<button>` by default, or a Next `<Link>` when `href` is passed (`newTab` adds `target="_blank"` + `rel`).

Client components (`"use client"`) are kept to the interactive pieces (site menu, news/project filtering, about section); the rest are server components.
